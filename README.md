# Eterrno Marketing Starter
Website and HTML email development practice.

## Eterrno Resort website

A simple, responsive one-page resort website.

| File | What it does |
| --- | --- |
| `index.html` | The page content: navigation, hero, about, rooms, experiences, gallery, enquiry form, footer |
| `css/styles.css` | All the styling. Change colours and fonts in the `:root` block at the top |
| `js/main.js` | Mobile menu, header scroll effect, gallery lightbox, form checks |

**To view it:** double-click `index.html` to open it in your browser.

**To edit text:** open `index.html` in a code editor (for example VS Code), change the words, save, and refresh the browser.

**To use your own photos:** put them in a new `images/` folder and change an image's `src`, for example `src="images/pool.jpg"`.

**Note:** the enquiry form doesn't send emails yet. To receive enquiries, connect it to a form service such as Formspree or Netlify Forms.
